# Economia — Números Base

Moedas: Essência (intra-run XP), Fragmentos (meta Forja), Cristais premium (passe/ranking, server-side).
Run média: 800 Essência + 40 Fragmentos.
Forja: custo `50 * 1.6^lvl` por atributo (Vida, Dano, Área, Armadura, Atração), máx lvl 20 inicial.
Mastery Fenda I-X: HP/dano inimigo x1.15/tier, drop x1.2/tier.
Relíquias (4 slots, trade-off real): Ganância +25% drop -10% vida, Vampírica 2% dano cura, Ritmo +área -velocidade, Fenda +EXP elite.
Passe 60 dias: free (recursos + 1 skin básica), premium (skins 3D, VFX arma, pet coleta, moldura).
Ads: só pós-run — dobrar Fragmentos OU 1 revive/run. Sem pop-up mid-run, sem paywall poder.
Simulação alvo: 20 runs = +30% poder (não +300%).
