# GDD Resumido — Pulsar Survivor

## Fantasia
Sobreviva à Fenda Abissal como herdeiro de linhagens esquecidas (Egito, Suméria, Nórdica esotérica, Africana, Mesoamericana). Cada run é um ritual: quanto mais caos, mais poder.

## Loops
- **Core 30s:** mover → matar → coletar Essência → escolher upgrade.
- **Run 15-20min:** horda crescente + chefes Fenda 5/10/15 → vitória/morte → Fragmentos → Forja.
- **Meta:** Forja (Vida, Dano, Área, Armadura, Atração) + Mastery Fenda I-X + Relíquias (4 slots) + desbloqueio Raça/Classe.

## Win/Lose
- Win: sobreviver 15min + matar chefe final. Infinito: recorde de tempo.
- Lose: HP 0. Pós-run: 1 revive opcional via ad, senão coleta Fragmentos.

## Câmera e controles
- Top-down 45-55°, distância 12-16m, smooth follow + zoom-out por intensidade.
- Mobile: joystick virtual dinâmico + auto-mira. PC: WASD + mouse.
- Acessibilidade: outline player ciano + blob shadow, modo daltônico laranja/azul, escala UI, vibração desligável, toggle 30/60fps.

## Requisitos anti-dores FASE1 (testáveis)
1. Legibilidade: projétil inimigo sempre camada superior, máx 30 transparências sobrepostas.
2. Perf: 500 inimigos 30fps no intermediário antes de mirar 1000.
3. End-game: Mastery X + Infinito + ranking semanal top100 cosmético.
4. Sinergia real: Raça+Classe gera híbrida que muda gameplay, não só número.
