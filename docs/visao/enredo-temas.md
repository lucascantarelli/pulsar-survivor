# Enredo e temas — Fenda Abissal (guia p/ content-designer)

## Premissa
Fenda como ritual hermetico: cada run e uma provacao; poder vem de entender o principio, nao so de numero.
## Temas por principio
Polaridade (Khemri): perda vira escudo. Ritmo (Var): compasso da mare. Correspondencia (Geometrista): micro espelha macro. Causa-Efeito + Ritmo (Cantora): marca e detona.
## Estrutura narrativa da run
Min 0-5 descoberta; 5 chefe Fenda I (teste); 10 chefe Fenda II (virada); 15 chefe final (julgamento). Infinito: ecos sem fim.
## Expansao 10x10
Cada nova raca ancora num mito real (Suméria, Mesoamerica, Africa) + principio distinto; cada classe ancora num arquétipo (tank, controle, suporte, burst) + ativa unica.
