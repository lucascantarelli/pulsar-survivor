# Lore — Raças x Classes (Hermetismo, sem clichê)

Preserva o Prompt Mestre da FASE2, adaptado para Godot (não HDRP).

## Canon
Sete Princípios Herméticos como mecânicas: Mentalismo (ilusão), Correspondência (espelho), Polaridade (troca HP/dano), Ritmo (pulso), Causa e Efeito (marca/detonação), Gênero (criação/entropia).

## Template Raça
- Nome original sonoro (banido "Elfo da floresta", "Anão mineiro").
- Origem ancestral + mito real/esoterismo.
- Passiva sobrevivência + Ativa racial em área com VFX orçado.

## Template Classe
- Nome + arquétipo, ataque base auto/ativo, única de classe (aura/feixe/fractal).

## Sinergia
Raça+Classe gera mutação visual (chifres/cristais/veios emissivos) + híbrida especial.

## 2x2 iniciais (validar pipeline Resource antes do 10x10)
- **Khemri Cinzenta (Egito, Polaridade):** passiva converte 20% dano recebido em escudo temporário; ativa Detonação Polar em área.
- **Vár-Brjóst (Nórdica esotérica, Ritmo):** pulso a cada 4s aumenta atração + dano.
- **Geometrista de Cinzas (classe):** fractais giratórios que escalam com área.
- **Cantora de Fenda (classe):** onda rítmica que empurra horda.
- Híbridas ex: Marca Polar + Detonação Rítmica.

Pipeline: content-designer gera fichas → tech-art valida budget → vira BaseRaca.tres / BaseClasse.tres. Escala para 10x10 só após 2x2 aprovado.
